# Clair

> Clair Inc is a financial technology company that provides free, compliant On-Demand Pay (earned wage access) as an embedded service inside the payroll, time-and-attendance and workforce-management platforms employees already use. Partners connect to Clair over a partner REST API that carries employee, employment and attendance data; Clair originates 0% APR earned wage advances through its FDIC-insured partner bank, Pathward N.A., and partners embed a Clair-hosted user experience so employees can take an advance and handle loan servicing without a separate login.

This file is generated by API Evangelist from the public surface of getclair.com and the getclair GitHub organization. It is not published by Clair.

## API surface

Clair operates a partner REST API for earned wage access, but publishes no public developer portal, API reference, or machine-readable specification. API documentation is released only to contracted partners through the partner program (contact sales@getclair.com). No OpenAPI, AsyncAPI, GraphQL, MCP, or A2A agent card was found on any Clair host as of 2026-08-09.

## SDKs

Clair ships first-party iOS client libraries as Swift Package Manager binary XCFrameworks from its GitHub organization. There are no npm, PyPI, Maven, NuGet, RubyGems, Packagist, Go or crates.io packages.

- [ClairKit](https://github.com/getclair/clair-ios-sdk): core iOS framework for the embedded Clair experience (1.2.6).
- [ClairGustoKit](https://github.com/getclair/clair-gusto-kit): iOS kit for the Gusto Embedded Payroll integration (1.2.0).
- [ClairQuickbooksKit](https://github.com/getclair/clair-sdk-ios): iOS kit for the QuickBooks/Intuit payroll integration (0.0.31).
- [ClairSdkPoc](https://github.com/getclair/ios-sdk-poc): example Swift package for prospective partners to test an SDK integration (MIT).
